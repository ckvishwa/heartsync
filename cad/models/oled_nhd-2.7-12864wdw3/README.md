## Notes

- The stand-in was bare 73 x 41.9 x 1.8 glass. This module is 82 x 47.5 on a PCB: glass 2.5 + PCB 1.0 + the header area makes 6.74 deep in the STEP. It brings the glass's back face 4.9 mm closer to the carrier and needs more room around the window.
- STEP frame: glass face on -Z (Z 54.23), PCB Z 56.73..57.73, X -7.11..74.89, Y 21.90..72.39 (vendor origin, not centred).
