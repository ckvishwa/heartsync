# PETG: final enclosure and dock

Better heat resistance and toughness than PLA. Used for the Phase 11 build.

Starting point. Check the filament maker's recommended range, then record what worked.

| Setting | Starting value | What worked |
|---------|----------------|-------------|
| Nozzle temperature | maker's range (commonly around 230 to 250 °C) | |
| Bed temperature | maker's range (commonly around 70 to 85 °C) | |
| Layer height | 0.2 mm | |
| Walls | 4 | |
| Infill | 25 percent | |
| Cooling | reduced compared with PLA | |

Notes:

- Dry the filament first; wet PETG strings and weakens layers.
- PETG shrinks differently from PLA: re-check `fit_clearance` with a PETG test slice.
- Gasket channel and seam faces: print face-up where possible for a clean sealing surface.
- No heat-set inserts near the battery pocket after the cell is installed.
