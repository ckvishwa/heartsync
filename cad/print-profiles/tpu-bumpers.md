# TPU: bumpers and feet

Flexible parts: corner bumpers, dock feet, possibly the seam gasket.

Starting point. Check the filament maker's recommended range, then record what worked.

| Setting | Starting value | What worked |
|---------|----------------|-------------|
| Shore hardness | 95A is the easiest to print | |
| Nozzle temperature | maker's range (commonly around 220 to 240 °C) | |
| Bed temperature | maker's range (commonly around 40 to 60 °C) | |
| Print speed | slow (about 20 to 30 mm/s) | |
| Retraction | minimal | |
| Layer height | 0.2 mm | |

Notes:

- A direct-drive extruder is strongly preferred for TPU.
- Dry the filament first.
- A printed TPU gasket is not guaranteed to seal to IP54; test it with water spray
  on an empty shell before trusting it.
